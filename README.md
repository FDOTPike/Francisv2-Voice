## Quick Start (Run Francisv2 on Your Computer)

### 1. Prerequisites
1. **GPT-SoVITS v2 / v2Pro** installed on a computer with an NVIDIA GPU (8 GB+ VRAM recommended, e.g. RTX 3070 Ti) or Apple Silicon Mac:
   - Download the official integrated package from [GPT-SoVITS Releases](https://github.com/RVC-Boss/GPT-SoVITS/releases) and extract it (e.g. to `C:\GPT-SoVITS`).
2. **Python 3.10+** for running the client agent (`voice_agent.py`).

### 2. Clone This Repository & Download the Weights
```bash
git clone https://github.com/FDOTPike/Francisv2-Voice.git
cd Francisv2-Voice
pip install -r requirements.txt

# Downloads Francisv2-e15.ckpt (155 MB) and Francisv2_e8_s344.pth (85 MB)
# from GitHub Release v1.0.0, verifies SHA256 hashes, and syncs to C:\GPT-SoVITS
python download_weights.py --gpt-sovits-dir "C:\GPT-SoVITS"
```

### 3. Start the Headless GPT-SoVITS Streaming Server
On Windows, double-click **`start_francisv2_server.bat`** or run:
```bat
start_francisv2_server.bat
```
*(Or manually inside your GPT-SoVITS folder: `runtime\python.exe api_v2.py -a 0.0.0.0 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml`)*

### 4. Generate Speech or Run the Real-Time Voice Agent

#### Option A: Synthesize Any Text to Speech (CLI)
```bash
python voice_agent.py --say "G'day! This is Francis v2 running locally on GPT-SoVITS. Feel free to use this voice in your own projects as long as you credit Francisv2." --out my_output.wav
```

#### Option B: Interactive Real-Time Conversational Voice Agent (Mic -> Whisper -> Llama 3.3 -> Francisv2)
1. Get a free API key at [console.groq.com](https://console.groq.com/keys).
2. Set `GROQ_API_KEY` in your environment and run:
```bash
# Windows PowerShell
$env:GROQ_API_KEY="gsk_your_key_here"
python voice_agent.py
```

#### Option C: Call the HTTP API Directly from Any Language
Once `api_v2.py` is running on port `9880` and the weights are loaded, you can synthesize speech from Python, Node.js, C#, or `curl`:
```bash
# 1. Load Francisv2 weights
curl "http://127.0.0.1:9880/set_gpt_weights?weights_path=GPT_weights_v2/Francisv2-e15.ckpt"
curl "http://127.0.0.1:9880/set_sovits_weights?weights_path=SoVITS_weights_v2/Francisv2_e8_s344.pth"

# 2. Request TTS audio
curl -X POST "http://127.0.0.1:9880/tts" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello from Francisv2!",
    "text_lang": "en",
    "ref_audio_path": "ref.wav",
    "prompt_text": "2017 he finished. If I went to uni one year early, which I could have.",
    "prompt_lang": "en",
    "media_type": "wav"
  }' --output output.wav
```

| Asset | File | Size | SHA-256 Checksum |

### Training Summary
- **Base Architecture:** GPT-SoVITS v2 (`s2G2333k.pth` / `s1bert25hz-5kh-longer-epoch=12-step=369668.ckpt`)
- **Dataset:** Curated 86 high-clarity Australian English clips (`7.02 minutes` net active speech after 80 Hz high-pass filtering, EBU R128 `-16 LUFS` loudness normalization, and Faster-Whisper `large-v3-turbo` verification)
- **SoVITS Training:** 8 epochs (`344` steps, `batch_size=4`, `fp16_run=True`)
- **GPT Training:** 15 epochs (`330` steps, `batch_size=4`, `90.7%` top-3 token accuracy)
